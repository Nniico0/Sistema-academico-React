# Sistema Académico UNAB

## Descripción

Sistema web de gestión académica desarrollado con React.

El proyecto corresponde a una interfaz orientada a la gestión de procesos académicos de estudiantes. Actualmente contempla el registro de un estudiante y la inscripción de asignaturas.

El sistema busca centralizar la información académica y facilitar procesos que anteriormente podían realizarse mediante distintos medios, como formularios, archivos y hojas de cálculo.

## Funcionalidades actuales

El proyecto cuenta actualmente con las siguientes funcionalidades:

- Registro de información de un estudiante.
- Validación de campos obligatorios.
- Visualización de los datos registrados.
- Acceso a la inscripción de asignaturas.
- Visualización de asignaturas disponibles.
- Visualización de docente, horario y cupos disponibles.
- Inscripción de asignaturas.
- Visualización de las asignaturas inscritas.
- Navegación entre las diferentes vistas mediante React Router.
- Diseño responsive para distintos tamaños de pantalla.

## Tecnologías utilizadas

- React
- JavaScript
- JSX
- CSS
- Vite
- React Router DOM
- HTML5

- Proyecto frontend desarrollado con React.
